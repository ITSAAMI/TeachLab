# Code Academy — Full Stack Development

**Path:** `TeachLab/Code-Academy/Full-Stack-Development`

## Overview

End-to-end web application engineering combining React/Next.js frontends with Node.js/Python backends and production databases.

## Topics & Course Roadmap to Cover

1. **Week 01: Modern Frontend Foundations (HTML5, CSS Grid/Tailwind, JavaScript ES6+)**
2. **Week 02: React.js Component Architecture, Hooks & Client-Side Routing**
3. **Week 03: Node.js & Express REST API Architecture**
4. **Week 04: Database Modeling with PostgreSQL / MongoDB & ORM/ODM**
5. **Week 05: Full-Stack Authentication (JWT/Cookies), Protected Routes & State Sync**
6. **Week 06: Full-Stack Capstone Project, CI/CD Pipeline & Cloud Hosting**
