# Code Academy — Backend Development

**Path:** `TeachLab/Code-Academy/Backend-Development`

## Overview

Server-side engineering covering HTTP, RESTful API design, Node.js/Express, Python (Django/Flask), relational/NoSQL databases, authentication, and testing.

## Topics & Course Roadmap to Cover

1. **Week 01 (Basic): HTTP Protocol, Client-Server Architecture, JSON & Node.js Runtime**
2. **Week 02 (Basic -> Int): Express.js Routing, Middleware, Controllers & Error Handling**
3. **Week 03 (Intermediate): Relational (PostgreSQL/MySQL) & NoSQL (MongoDB) Integration**
4. **Week 04 (Int -> Adv): Authentication & Authorization (JWT, Sessions, OAuth2, RBAC)**
5. **Week 05 (Advanced): Caching (Redis), File Uploads, Rate Limiting & API Security**
6. **Week 06 (Advanced+): Automated API Testing, Dockerization & Cloud Deployment**
