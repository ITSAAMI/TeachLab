# Code Academy — Web Development

**Path:** `TeachLab/Code-Academy/Web-Development`

## Overview

Foundational to advanced web technologies covering HTML5, CSS3, Bootstrap 5, Tailwind CSS, JavaScript, DOM, APIs, and backend basics.

## Topics & Course Roadmap to Cover

1. **Module 01: Semantic HTML5, Forms, Tables & Accessibility (WCAG)**
2. **Module 02: Modern CSS3, Flexbox, CSS Grid & Responsive Web Design**
3. **Module 03: CSS Frameworks — Bootstrap 5 & Tailwind CSS**
4. **Module 04: Interactive JavaScript ES6+, DOM Events & Browser Storage**
5. **Module 05: Asynchronous JS, Fetch API, JSON & RESTful Services**
6. **Module 06: Modern Frontend Frameworks (React.js) & Deployment**
