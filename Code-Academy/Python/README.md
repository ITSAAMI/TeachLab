## Topics & Course Roadmap to Cover

1. **Week 01 (Basic): Python Syntax, Variables, Conditionals, Loops & Functions**
2. **Week 02 (Basic -> Int): Lists, Tuples, Sets, Dictionaries & List Comprehensions**
3. **Week 03 (Intermediate): File I/O (CSV/JSON), Exception Handling & Modules/Packages**
4. **Week 04 (Int -> Adv): Object-Oriented Programming (Classes, Dunder Methods, Inheritance)**
5. **Week 05 (Advanced): Iterators, Generators, Decorators, Virtual Environments & Pytest**
6. **Week 06 (Capstone): Automation Scripts, REST API Client & Mini Web/Data Project**
