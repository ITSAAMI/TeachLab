# Frontend Development — 6-Week Step-by-Step Assignments

Welcome to the **Frontend Development Course Assignments** at **TeachLab / Code-Academy**.  
These **6 progressive assignments** are structured step-by-step from **Basic (Week 01)** to **Advanced+ Capstone (Week 06)**, covering the complete modern frontend stack:

1. **HTML5 & Core CSS3**
2. **Responsive Layouts (Flexbox & CSS Grid)**
3. **Bootstrap 5 (Component-First Framework)**
4. **Tailwind CSS (Utility-First Styling & Dark Mode)**
5. **JavaScript ES6+, DOM Manipulation, LocalStorage & Fetch API**
6. **React.js (Components, Hooks, State, Routing & API Integration)**

## General Submission Rules for All 6 Assignments

1. **Folder Naming:** Create a folder named `RollNo_YourName_Assignment_0X` for each week.
2. **Clean Code:** Properly indent all HTML, CSS, JS, and JSX code; include brief comments explaining major sections.
3. **Responsive Check:** From Week 02 onward, every assignment must be tested at **Desktop (`1280px+`)**, **Tablet (`768px`)**, and **Mobile (`375px`)** widths with zero horizontal scrolling.
4. **Accessibility:** Always include `alt` attributes on images, `<label for="...">` on form inputs, and semantic landmarks (`<header>`, `<nav>`, `<main>`, `<section>`, `<footer>`).
