# Code Academy — Frontend Development

**Path:** `TeachLab/Code-Academy/Frontend-Development`

## Overview

Step-by-step 6-week frontend engineering course progressing from semantic HTML5 & CSS3 to Bootstrap 5, Tailwind CSS, JavaScript ES6+, and React.js SPAs.

## Subfolders in This Section

- [`Assignments/`](./Assignments/README.md) — Assignments materials and exercises

- [`Projects/`](./Projects/README.md) — Projects materials and exercises

## Topics & Course Roadmap to Cover

1. **Week 01 (Basic): HTML5 Semantics, Tables, Accessible Forms & Core CSS Box Model**
2. **Week 02 (Basic -> Int): Modern CSS Variables, Flexbox, CSS Grid & Responsive Media Queries**
3. **Week 03 (Intermediate): Bootstrap 5 Grid, Navbar, Offcanvas, Modals, Cards & Validation**
4. **Week 04 (Int -> Adv): Tailwind CSS Utility-First Design, Bento Grids & Dark Mode**
5. **Week 05 (Advanced): JavaScript ES6+, DOM Manipulation, LocalStorage & Async Fetch API**
6. **Week 06 (Advanced+ Capstone): React.js Components, Props, Hooks (useState/useEffect) & SPA**
