# Frontend Development Bootcamp — Complete 6-Week Curriculum

**Course Track:** Code-Academy / Frontend Development  
**Core Stack:** HTML5 • CSS3 (Flexbox & Grid) • Bootstrap 5 • Tailwind CSS • JavaScript (ES6+) • React.js

---

## Course Overview

This 6-week hands-on curriculum takes students from writing their first semantic HTML5 tag to building and deploying a modern **React.js + Tailwind CSS Single-Page Application (SPA)**. Every week pairs structured lectures and live classwork with a progressive, step-by-step assignment (`Assignment 01` through `Assignment 06`).

---

## Week-by-Week Syllabus

### Week 01: HTML5 Semantics & Core CSS3 Foundations (Level: Basic)
- **Module 1.1 — Web Fundamentals & HTML5 Boilerplate:** How browsers render pages, DOM tree basics, `<head>` metadata, SEO & viewport tags.
- **Module 1.2 — Semantic HTML5 Landmarks:** `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<aside>`, `<footer>`, headings (`h1`–`h6`), lists, links, and responsive images.
- **Module 1.3 — Data Tables & Accessible Forms:** `<table>`, `<thead>`, `<tbody>`, `<tfoot>`, `<form>`, `<fieldset>`, `<legend>`, `<label for>`, input types, and HTML5 validation attributes.
- **Module 1.4 — CSS3 Selectors, Typography & The Box Model:** Cascade & specificity, colors (`hex`, `rgb`, `hsl`), Google Fonts (`Inter`), `margin`, `padding`, `border`, `border-radius`, `box-shadow`, and `box-sizing: border-box`.
- **Weekly Assignment:** [Week 01 — Assignment 01: HTML5 & Core CSS Basics](../Assignments/Week-01-Assignment-01-HTML-CSS-Basics.md)

---

### Week 02: Modern Responsive CSS Layouts — Flexbox & CSS Grid (Level: Basic → Intermediate)
- **Module 2.1 — CSS Custom Properties & Design Tokens:** Defining reusable variables in `:root` for colors, spacing, shadows, and radii.
- **Module 2.2 — 1D Layouts with Flexbox:** `display: flex`, `flex-direction`, `justify-content`, `align-items`, `flex-wrap`, `gap`, `flex: 1`, and `margin-inline-start: auto`.
- **Module 2.3 — 2D Layouts with CSS Grid:** `display: grid`, `grid-template-columns`, `fr` units, `minmax()`, `repeat(auto-fit, minmax(280px, 1fr))`, and `grid-template-areas`.
- **Module 2.4 — Sticky Headers, Fluid Typography & Media Queries:** `position: sticky`, `backdrop-filter: blur()`, fluid sizing with `clamp()`, logical properties, and responsive breakpoints (`@media`).
- **Classwork Reference:** [../Classwork/layout.html](../Classwork/layout.html)
- **Weekly Assignment:** [Week 02 — Assignment 02: Responsive Flexbox & Grid Website](../Assignments/Week-02-Assignment-02-Responsive-Flexbox-Grid.md)

---

### Week 03: Bootstrap 5 Rapid UI Engineering (Level: Intermediate)
- **Module 3.1 — Bootstrap 5 Architecture & 12-Column Grid:** Containers (`.container`, `.container-fluid`), `.row`, responsive column breakpoints (`.col-12`, `.col-sm-6`, `.col-md-4`, `.col-lg-3`), and gutters (`.g-4`).
- **Module 3.2 — Navigation & Layout Components:** `.navbar`, `.navbar-expand-lg`, `.offcanvas` drawer, breadcrumbs, and `.nav-pills` tabs.
- **Module 3.3 — Interactive UI Components:** `.card`, `.badge`, `.accordion`, `.modal`, `.alert`, `.toast`, and `.progress`.
- **Module 3.4 — Bootstrap Forms & Utility API:** `.form-control`, `.form-select`, `.form-floating`, `.input-group`, validation states (`.needs-validation`), and spacing/flex utilities (`p-*`, `m-*`, `d-flex`, `gap-*`).
- **Weekly Assignment:** [Week 03 — Assignment 03: Bootstrap 5 Storefront & Admin UI](../Assignments/Week-03-Assignment-03-Bootstrap-5-UI.md)

---

### Week 04: Tailwind CSS Utility-First Design System & Dark Mode (Level: Intermediate → Advanced)
- **Module 4.1 — Utility-First Philosophy & Setup:** Comparing component frameworks (Bootstrap) vs. utility-first CSS (Tailwind CSS), Vite/Play CDN setup, and custom theme tokens.
- **Module 4.2 — Responsive Design & State Variants:** Mobile-first prefixes (`sm:`, `md:`, `lg:`, `xl:`), interactive states (`hover:`, `focus-visible:`, `active:`), and parent state styling (`group`, `group-hover:`).
- **Module 4.3 — Modern SaaS Visual Patterns:** Gradients (`bg-gradient-to-r`, `bg-clip-text`), glassmorphism (`backdrop-blur-md`, `bg-white/75`), rings (`ring-2`), and asymmetric **Bento Grids** (`col-span-2`, `row-span-2`).
- **Module 4.4 — Dark Mode Architecture:** Configuring `darkMode: 'class'`, styling `dark:*` variants, and building a theme switcher.
- **Weekly Assignment:** [Week 04 — Assignment 04: Tailwind CSS AI SaaS Landing Page](../Assignments/Week-04-Assignment-04-Tailwind-CSS-Modern-UI.md)

---

### Week 05: Interactive JavaScript — ES6+, DOM, LocalStorage & Fetch API (Level: Advanced)
- **Module 5.1 — Core JavaScript & Modern ES6+:** `let` vs `const`, template literals, arrow functions, destructuring, spread/rest operators, and ES modules (`import`/`export`).
- **Module 5.2 — Data Transformation with Array Methods:** Mastering `.map()`, `.filter()`, `.reduce()`, `.find()`, `.some()`, `.every()`, and `.sort()`.
- **Module 5.3 — DOM Manipulation & Event Delegation:** `querySelector`, dynamic rendering, form submission handling, inline validation, and event bubbling/delegation.
- **Module 5.4 — Browser Storage & Async REST APIs:** Persisting state in `localStorage` (`JSON.stringify` / `JSON.parse`), `Promises`, `async` / `await`, `fetch()`, HTTP status codes, loading skeletons, and `try / catch` error handling.
- **Weekly Assignment:** [Week 05 — Assignment 05: Smart Tracker & Live GitHub Finder](../Assignments/Week-05-Assignment-05-JavaScript-DOM-APIs.md)

---

### Week 06: React.js Modern Frontend Development (Level: Advanced+ Capstone)
- **Module 6.1 — Thinking in React & Vite Setup:** Component-driven architecture, JSX rules, Vite project structure, and styling React with Tailwind CSS / Bootstrap 5.
- **Module 6.2 — Components, Props & Conditional Rendering:** Passing data & callbacks via `props`, rendering lists with `.map()` and unique `key` props, conditional badges and empty states.
- **Module 6.3 — State Management (`useState`) & Controlled Forms:** Reactive state updates, immutability with arrays/objects, derived state for live search/filtering/sorting, and controlled form inputs.
- **Module 6.4 — Side Effects (`useEffect`), Custom Hooks & Deployment:** Data fetching in `useEffect`, cleanup functions, building a reusable `useLocalStorage` hook, React Router basics, and deploying to Vercel/Netlify.
- **Weekly Assignment (Capstone):** [Week 06 — Assignment 06: React.js Course & Store SPA](../Assignments/Week-06-Assignment-06-React-JS-Capstone.md)
