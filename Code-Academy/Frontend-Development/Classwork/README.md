# Frontend Development — Classwork

**Path:** `TeachLab/Code-Academy/Frontend-Development/Classwork`

## Overview

Step-by-step 6-week frontend engineering course progressing from semantic HTML5 & CSS3 to Bootstrap 5, Tailwind CSS, JavaScript ES6+, and React.js SPAs.

## Topics & Course Roadmap to Cover

1. **Week 01 Live Coding: Starter boilerplate & foundational syntax walkthrough**
2. **Week 02 Live Coding: Responsive layout / modular structure implementation**
3. **Week 03 Live Coding: Component patterns & interactive exercises**
4. **Week 04 Live Coding: Utility styling, debugging & refactoring session**
5. **Week 05 Live Coding: Dynamic data handling & asynchronous API demo**
6. **Week 06 Live Coding: Capstone architecture & code review session**
