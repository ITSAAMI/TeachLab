# Frontend Development — Projects

## Overview

Step-by-step 6-week frontend engineering course progressing from semantic HTML5 & CSS3 to Bootstrap 5, Tailwind CSS, JavaScript ES6+, and React.js SPAs.

## Topics & Course Roadmap to Cover

1. **Project 01 (Starter): Beginner-friendly single-module project**
2. **Project 02 (Intermediate): Multi-feature application with persistent data**
3. **Project 03 (Capstone): Production-style portfolio project with README & live demo**
