# Code Academy — Cybersecurity

**Path:** `TeachLab/Code-Academy/Cybersecurity`

## Overview

Defensive and offensive security training covering networking, Linux hardening, cryptography, web security (OWASP Top 10), forensics, and CTF labs.

## Topics & Course Roadmap to Cover

1. **Week 01: Networking Fundamentals (TCP/IP, OSI, DNS, HTTP/TLS, Wireshark)**
2. **Week 02: Linux Security, Permissions, Bash Scripting & System Hardening**
3. **Week 03: Applied Cryptography (Hashing, Symmetric/Asymmetric Encryption, PKI)**
4. **Week 04: Web Application Security & OWASP Top 10 (SQLi, XSS, CSRF, SSRF)**
5. **Week 05: Threat Modeling, Secure Coding Practices & Vulnerability Scanning**
6. **Week 06: Digital Forensics, Incident Response & Capture-The-Flag (CTF) Labs**
