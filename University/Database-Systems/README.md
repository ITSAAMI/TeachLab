# University — Database Systems

**Path:** `TeachLab/University/Database-Systems`

## Overview

Database architecture, ER modeling, normalization, SQL mastery (PostgreSQL & MySQL), indexing, transactions, and NoSQL document stores (MongoDB).

## Topics & Course Roadmap to Cover

1. **Module 01: Relational Model, ER Diagrams & Schema Normalization (1NF-3NF/BCNF)**
2. **Module 02: Core SQL (DDL, DML, Joins, Aggregations, Subqueries, CTEs & Window Functions)**
3. **Module 03: PostgreSQL & MySQL Administration, Indexing & Query Optimization**
4. **Module 04: Transactions, ACID Properties, Concurrency Control & Backups**
5. **Module 05: NoSQL Databases — MongoDB Document Modeling, Aggregation Pipeline & Indexing**
