# University — Mobile App Development

**Path:** `TeachLab/University/Mobile-App-Development`

## Overview

Cross-platform mobile engineering using Flutter (Dart) and React Native (Expo), covering UI layouts, navigation, state management, and native APIs.

## Topics & Course Roadmap to Cover

1. **Week 01: Dart / JavaScript ES6+ Essentials & Mobile UI Principles**
2. **Week 02: Core Widgets / Components, Flexbox & Responsive Mobile Layouts**
3. **Week 03: Multi-Screen Navigation, Routing & Deep Linking**
4. **Week 04: State Management, Forms & Local Persistence (SQLite / AsyncStorage)**
5. **Week 05: REST API Integration, Authentication & Push Notifications**
6. **Week 06: Device Sensors, Performance Profiling & App Store Deployment**
